## Project Structure
- **package.json**: Defines dependencies (Express, Mongoose, Multer, Axios, etc.)
- **server.js**: Main server file with Express setup, MongoDB connection, and API routes
- **History.js**: MongoDB schema for storing classification history
- **classify.js**: API endpoints for classification, history, feedback, and analytics
- **index.html**: Frontend HTML with upload/camera interface and tabs
- **style.css**: Basic styling for the app
- **app.js**: JavaScript for handling image upload, camera capture, API calls, and UI updates
- **.env**: Environment variables for MongoDB URI and Hugging Face API key
- **README.md**: Setup and usage instructions
- **.gitignore**: Ignores node_modules and sensitive files

## Key Features Implemented
- **Image Upload/Camera**: Users can upload files or capture photos using device camera
- **AI Classification**: Integrates with Hugging Face API using the nikhilroxtomar/garbage-classification model
- **Disposal Guidance**: Shows recyclable status and bin color based on category
- **History Tracking**: Saves all predictions to MongoDB
- **User Feedback**: Allows users to mark predictions as correct/incorrect
- **Analytics**: Displays total predictions, accuracy percentage, and top classified items

## Setup Instructions
1. Install dependencies: `npm install`
2. Set up MongoDB (local or Atlas) and update .env
3. Get Hugging Face API key and add to .env
4. Run: `npm start`
5. Open `http://localhost:3000`

The server is currently running in the background. The app is ready to use once you configure the database and API key. The frontend provides a clean interface for waste classification with real-time feedback and analytics.
